# AI Chat App — Node.js 全栈聊天网站（v2 升级版）

> 在你给的 py.zip 基础上做了三处升级。详见底部「本次改动」。

## 功能
- 注册 / 登录（密码 scrypt 哈希，HttpOnly Cookie 会话）
- 每个用户的账号、会话、聊天记录**完全隔离**
- **邮箱绑定**：绑定/修改邮箱需输入登录密码确认身份，邮箱全网唯一
- 会话管理：新建 / 切换 / 删除
- 聊天记录持久化（SQLite），刷新不丢失
- **SSE 流式输出**：AI 回复逐字显示
- **联网三态开关（新增）**：🔍 自动 / 🌐 强制联网 / 🚫 关闭联网，点工具栏按钮循环切换
- **16 个字段化技能（重做）**：每个技能按需配置场景/语言/风格等下拉，写文案不再死磕朋友圈
- **对话记忆**：用户与 AI 消息均持久化，多轮上下文完整传递
- **对话标题自动总结**：AI 生成 10 字以内标题，流式推送并持久化
- **模型选择**：侧栏与输入区工具栏双下拉框、双向同步，自动拉取上游可用模型
- **代码高亮**：marked + highlight.js（GitHub Dark 主题，本地化引入、离线可用）
- **新话题按钮**：顶部栏一键开启新对话
- **AI 思考动画**：呼吸点 + 头像光晕
- 界面：紫蓝渐变科技风，左侧会话列表 + 右侧聊天区，移动端自适应
- API Key 仅保存在后端，前端不可见

## 技术栈
- 后端：Node.js + Express + better-sqlite3
- 前端：原生 HTML / CSS / JavaScript（无框架）
- 上游：OpenAI 兼容接口，多地址自动故障转移

## 目录结构
```
ai-chat-app/
├── server.js          # 后端服务（认证、会话、流式代理）

    ├── style.css      # 样式
```

## 运行
```bash
cd ai-chat-app
npm install        # 第一次运行需要
npm start
# 浏览器打开 http://localhost:3000
```
首次启动会在 `data/app.db` 自动建库。

### B) 接入智谱 AI（GLM）Provider + 自动故障转移（v2.2）

#### B1) 智谱 API 接入
- 新增智谱开放平台端点 `https://open.bigmodel.cn/api/paas/v4`（用户提供 key），与 poixe 三个节点共存。
- 多 Provider 架构：每个端点独立维护 base / apiPath / key，请求按端点自动注入对应密钥，互不干扰。

#### B2) 8 个智谱模型（官方 2026-10 核验）
**无限免费（4 个）**：
- `zhipu:glm-4-flash-250414` — 128K 上下文 / 16K 输出，最老牌免费模型
- `zhipu:glm-4.7-flash` — 200K 上下文 / 128K 输出，最新免费文本模型
- `zhipu:glm-4.5-flash` — 128K / 96K
- `zhipu:glm-z1-flash` — 128K，推理模型

**低价按量（4 个，用赠送 token 额度调用）**：
- `zhipu:glm-4-flashx-250414`（0.1 元/M）、`zhipu:glm-z1-flashx`（0.1 元/M）、`zhipu:glm-4.7-flashx`（0.5 元/M）、`zhipu:glm-4.5-air`（0.8 元/M）

前端下拉统一显示为「智谱 · 模型名」。

#### B3) poixe 不可用时自动切换智谱
- `fetchUpstream` 重构：poixe 三个节点按序轮询（含 5xx/429/408/超时/网络错误转移），**全部不可用时自动 fallback 到智谱免费模型** `glm-4-flash-250414` 继续生成，并向前端推送 `notice` 事件提示「主节点不可用，已自动切换至智谱 AI」。
- 智谱免费模型偶发 429（"访问量过大"类瞬时限流）时自动退避 1.5s 重试一次。
- 搜索决策 / 对话标题等辅助任务：选智谱模型时固定走稳定免费模型，避免推理模型 reasoning 占满输出。

#### B4) 实测
- 智谱 key 直测：glm-4-flash-250414 / glm-4.5-flash / glm-z1-flash / glm-4-flashx-250414 流式调用全部 200。
- 模拟 poixe 全部不可达：`deepseek-chat:free` 请求自动收到 notice 并切智谱完成流式回复。
- 浏览器端到端：选「智谱 · glm-4-flash-250414」「智谱 · glm-4.5-air」对话均正常。

#### A8) 长内容不卡顿 + 生成提速
- 流式渲染节流：每 60ms 合并一次重渲染（原为每个 delta 全量渲染 Markdown，大段代码极卡）。
- 内容超过 8000 字符时，流式阶段改用纯文本 `textContent`，结束再整体渲染 Markdown + 高亮。
- `done` 事件到达**立即**渲染并解锁输入框，不再等服务端标题生成（最多白等 8 秒）。
- 去掉每次回复结束都拉取全量模型列表的 `loadModels()`（多余请求）。
- 新增 `window.__chatSeq` 序号防竞态：只有最新一次发送才有权解锁输入框/清理状态。
- 后端联动提速：搜索决策 `max_tokens` 120→80、超时 8s→6s。

### 0) 修复"对话消息要刷新才显示"（SSE 结束事件丢失）
旧 `app.js` 的流式解析在读到 `done` 结束帧时直接 `break`，且循环结束后**不处理残留 buffer**：
- 若最后一个 SSE 事件（`done`）恰好与结束帧同帧到达、或流末尾被代理/网络裁剪掉 `\n\n`，`done` 事件会被静默丢弃；
- 表现：AI 其实已经回复完毕并入库，但气泡一直停在"思考中"、输入框保持锁定，**只有刷新页面从数据库回放历史才看得到消息**。

新版三处加固：
1. 结束帧即使 `done=true` 也先把同帧数据拼入 buffer 再处理；
2. 流结束后冲刷残留 buffer，把未以 `\n\n` 结尾的最后一个事件处理掉；
3. 兜底：连接正常关闭但仍未收到 `done` 时，主动渲染已收到的内容并解锁输入；中途断流时保留已收到部分内容而非清空成错误。

### 1) 修了 AI 回复不显示的 bug
原 `app.js` 里 `stopThinking` 函数第一行写成了 `stopThinking();`（递归调用自己），导致每次流式响应收到 delta 都会无限递归爆栈，把后面的 `aiBubble.innerHTML = ...` 吞了。表现是：AI 在输出但不刷新页面看不到，刷新后从数据库回放历史反而能看见。
新版把 `stopThinking` 改成普通函数，不再调用自身。

### 2) 自动联网按钮改成三态开关
- 原先只是个状态徽章，"自动联网"几个字是死的，用户没法控制。
- 改成可点击按钮，三档循环：**🔍 自动** → **🌐 强制联网** → **🚫 关闭联网** → 回到自动。
- 颜色也变了：自动=蓝色、强制联网=绿色、关闭=灰色，一眼能看出当前状态。
- 后端 `/api/chat` 接 `web_mode` 参数：
  - `auto`（默认）：让 AI 决定要不要联网
  - `on`：强制联网，用消息原文做关键词，跳过 AI 决策（更快）
  - `off`：完全跳过搜索，不调任何外部接口
- 切换时会闪一下小动画做反馈。

### 3) 技能系统重做（从硬编码模板 → 字段化）
- 原 15 个技能每个都是写死的模板（如「写文案」=朋友圈文案、「写邮件」=邮件），用户只能填关键词。
- 新版 16 个技能，每个技能是一个「字段集合」+ 一个「prompt 生成器」：
  - **✍️ 写文案**：场景下拉（朋友圈/小红书/抖音/微博/公众号/知乎/广告语/短视频脚本/产品介绍/通用）+ 主题 + 语气 + 长度，不再死锁朋友圈
  - **📧 写邮件**：类型（工作汇报/请假/客户开发/求职信/催办…）+ 收件人 + 要点 + 语气
  - **💼 职场建议**：情境 + 你的身份
  - **🍳 菜谱推荐**：食材 + 菜系 + 难度
  - **🌍 旅行攻略**：目的地 + 天数 + 同行人 + 预算
  - **📚 学习计划**：内容 + 水平 + 周期 + 每日投入
  - **💪 健身计划**：目标 + 水平 + 场地 + 每周天数
  - **🧾 翻译润色**：原文 + 源语言 + 目标语言（中/英/日/韩/法/德/俄/西）+ 风格
  - **💡 头脑风暴**：主题 + 数量 + 切入角度
  - **📊 数据分析**：数据 + 分析目标
  - **🎯 面试准备**：岗位 + 公司 + 轮次
  - **🎬 影评剧评**：作品名 + 角度（剧情/演技/视听/主题/…）+ 长度
  - **🛒 购物建议**：想买什么 + 预算 + 侧重
  - **🧘 情绪疏导**：情绪 + 背景
  - **🔬 知识科普**：主题 + 受众
  - **🎯 自由任务**：新增的"无模板"入口，直接发任意任务给 AI
- 点技能后展开一个动态生成的表单（每个字段一行：label + 输入控件），填完按 Enter 或点 ↑ 发送。
- 必填项带 `*`，发送前会校验。
